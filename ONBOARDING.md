## Team Tips

- **Vibe coding is encouraged** — lean on Claude to move fast, but always read what it generates. The goal is to ship *and* understand.
- **This is a learning project** — if Claude does something you don't fully get, ask it to explain before moving on. Use Claude as a teacher, not just a code generator.
- **Transportation domain matters** — we're building in the transit/mobility space. When designing features, ask Claude to give you context on relevant industry concepts (GTFS feeds, multimodal routing, fare systems, etc.) so the code decisions make sense.
- **Web dev fundamentals first** — if you're newer to web dev, don't skip past the "why." Ask Claude to walk through the HTTP layer, DB schema tradeoffs, or API design choices as you build them.
